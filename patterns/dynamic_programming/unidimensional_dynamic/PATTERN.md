## Green flags for unidimensional dynamic programming

- Given one array and we need to find maximum or minimum, but we should not give all the elements.
- They ask us "how many ways" or "how many options" to do it.
  . Given a set of numbers and one int value, we need to find the minimum number of or check if is possible to ad up to that value.
- We need to find the largest sub-sequence with some property in one string or array.
